# 限界と倫理

## 守ること

1. **アドレスは人ではない。** 1 つのアドレスを複数人が使うことも、取引所の共用アドレスもあります。
   共用アドレスを加害者と取り違えない (報告書では「shared wallet contamination = 共用アドレスによる汚染」として明記)。
2. **確度を書く。** 事実 (ブロックチェーンに記録がある) / 推定 (振る舞いからの推測) / 未確認 を混ぜない。
3. **人物の公表をしない。** このリポジトリの事例も、アドレスと振る舞いまでで、個人名を出していません。
4. **AI を判定者にしない。** AI は提案と整理、記録の取得と検証は固定のコード、最終判断は人間。
5. **被害者を二次被害から守る。** 「資金を取り戻す」と持ちかける業者の多くは詐欺です。このリポジトリは依頼者から費用を取る前提を持ちません。

## 既知の弱点

- 事例は DeFi ハッキングで、詐欺事件での検証は未実施。
- 行動分析 (人手か自動か等) は統計的な推定で、誤る場合がある。
- 事例ごとの確度の区分は作者の判断に基づく (第三者による再評価は未実施)。

## 悪用の防止

追跡の手法は、追跡される側にも読めます。回避の助けになりすぎる記述 (特定の検知の回避手順など) は載せない方針です。
