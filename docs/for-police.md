# 警察の担当の方へ

捜査の代わりになるものではありません。被害者・弁護士が持ち込む資料が
**どう作られ、どこまで信頼でき、どう再現確認できるか**を、短時間で判断するための説明です。

## 持ち込み資料の再現確認

1. 報告書に載っている**取引 ID・アドレス**は、公開ブロックチェーン (ブロックエクスプローラ) で誰でも照合できます。
2. 証拠保全ログ (`evidence/*_api_log.jsonl`) は、1 行が 1 回の取得で、応答の SHA256 と UTC 時刻を含みます。
   同じ問い合わせをやり直し、SHA256 が一致するか比べられます (ブロックの確定済みの範囲では値は変わりません)。
3. 報告書の各主張は「事実 / 推定 / 未確認」に分かれています。**推定は捜査の端緒であり、結論ではありません。**

## このリポジトリが主張しないこと

- 人物の特定はしません。取引所の本人確認情報は、捜査機関の手続きでしか得られません。
- AI の出力は証拠ではありません。AI が提案した箇所は、必ず原データで確認してください。
- 国外の取引所・匿名化ツールを経由した先は、ここでは追えません。

## 連絡

捜査に役立つ形式 (列・用語・様式) の要望は Issue でお知らせください。
個人情報や進行中の事件の内容は、Issue に書かないでください。
