# 暗号資産詐欺の資金追跡 (AI 支援・公益目的・日本向け)

暗号資産を使った詐欺 (投資詐欺・ロマンス詐欺・なりすまし等) の被害を、
**弁護士と警察が追跡調査を進めやすくする**ための、無償・オープンな道具と手順書です。

被害者が送金した先を、公開されているブロックチェーンの記録から辿り、
「どの取引所のどの入金先に流れ着いたか」を、**後から第三者が再確認できる形**でまとめます。

## 誰のためのものか

| 読者 | 使いどころ | 入口 |
|:--|:--|:--|
| 弁護士・法律事務所 | 被害者の依頼を受けた時の初動の整理、交換業者への照会・保全の根拠資料づくり | [docs/for-lawyers.md](docs/for-lawyers.md) |
| 警察 (サイバー犯罪対策・詐欺捜査の担当) | 被害届の添付資料の読み方、追跡の再現確認 | [docs/for-police.md](docs/for-police.md) |
| 被害に遭った人 | まず何をするか | 下の「被害に遭ったら」 |

## 何ができるか

1. **資金の流れの追跡**: 被害者のウォレットから、中継ウォレット・ブリッジ (別のブロックチェーンへの橋渡し)・取引所の入金先まで辿る。
2. **証拠の保全**: 取得した記録 (API の応答) に SHA256 (内容が1字でも変わると値が変わる指紋) と UTC の時刻を付け、後から改ざんされていないと示せる形で残す。
3. **振る舞いの分析**: 操作の間隔・時間帯などから「人手か自動か」を推定する (推定であり、本人の特定ではない)。
4. **報告書の生成**: 事実・推定・未確認を分けて書く、決まった様式の報告書を作る。

AI (Claude などの大規模言語モデル) は「次にどこを調べるか」の提案と文章の整理を担い、
**記録の取得・指紋付け・検証は AI の判断に依らない固定のコード**が行います。
AI が書いた箇所は必ず人間が原データと照合してください。

## 正直な限界 (先に読んでください)

- **ここにある事例 20 件の元は DeFi のハッキング事件**で、詐欺事件そのものではありません。
  追跡の手順 (Phase 1〜4) は詐欺にもそのまま使えますが、**詐欺事件での実績はまだありません**。
  このリポジトリで公開している事例は 2 件 (`cases/`) だけです。
- **ブロックチェーンから分かるのはアドレスの動きまで**で、人物の特定はできません。
  特定は取引所の本人確認情報を持つ側 (捜査機関・裁判所の手続き) にしかできません。
- **「法廷で証拠として通る」ことは保証しません。** 証拠能力の判断は裁判所と専門家が行います。
  このリポジトリは「後から再確認できる形で残す」ことまでを目指しています。
- **誤った帰属は無実の人を傷つけます。** 詳細は [docs/limits-and-ethics.md](docs/limits-and-ethics.md)。
- 法的助言ではありません。

## 被害に遭ったら

- **警察相談専用電話 `#9110`** (全国共通・各都道府県警察の相談窓口につながります)。
- 送金の記録 (取引 ID・送金先アドレス・日時・やり取りの画面) を**消さずに**保存する。
- 追加の送金を求められても応じない。「返金には手数料が必要」は典型的な二次被害の手口です。
- 弁護士に相談する場合は、暗号資産の被害を扱う事務所か、最寄りの弁護士会の相談窓口へ。
